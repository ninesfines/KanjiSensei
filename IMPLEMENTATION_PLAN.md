# KanjiSensei — Implementation Plan

Interactive map of Kanji construction: explore kanji → decompose into radicals/components
→ discover kanji sharing those components. iOS-dark, minimalist, exploration-first.

Stack: React 19 + Vite + TypeScript · react-router-dom v7 · Cytoscape.js · plain CSS
(dark by default). Data: fully offline, generated by a Python build script from EDRDG /
JMDICT / KanjiVG / Kanjium open datasets.

## Phase 1 — Data pipeline (scripts/build_data.py)
- [x] Download pinned sources (stored out of repo, checksummed):
      kanjidic2-en, jmdict-eng-common, jmdict-examples-eng, radkfile, kradfile
      (jmdict-simplified 3.6.2 release JSONs), kanjium radicals.txt, KanjiVG XML
- [x] Emit src/data/kanji.json (2,136 jōyō + JLPT sets): kanji, meanings, jlpt,
      grade, freq, strokes, on/kun, radical{name,meaning,position}, components[]
- [x] Emit src/data/radicals.json: 214 kanxi radicals + variants, romaji name
      (ninben, ukanmuri…), meaning, stroke count
- [x] Derive per-kanji component POSITION from KanjiVG (hen/tsukuri/kanmuri/ashi/
      tare/nyou/kamae) and ROLE (semantic vs phonetic via kvg:phon + kanjium
      phonetics.txt)
- [x] Build reverse index: component char → [kanji] (from radkfile); words per kanji
      (jmdict-eng-common, top common + JLPT-sorted); sentences per kanji (examples
      file: jp + en pairs)
- [x] Variant canonicalization: 亻→人, 氵→水, 灬→火 etc. (Kanjium variant list)
- [x] Verification script: spot-check 族=[方,矢,𠂉], 私=[禾,厶], 家=[宀,豕];
      position=correct (家: 宀 top/kanmuri, 豕 bottom/ashi); 宀 reverse list includes
      家室安客宅宿官; 亻 reverse includes 住作使低体休

## Phase 2 — Core libs
- [x] src/lib/data.ts — typed loaders + in-memory indexes (single query layer;
      future features must consume only this)
- [x] src/lib/search.ts — match kanji char, meanings, on/kun (incl. romaji→kana),
      radical name/char/component, "JLPT N5", "8 strokes"; ranked instant results
- [x] src/lib/graph.ts — build Cytoscape elements (kanji/radical/component nodes;
      contains/uses/related edges) for a scoped subgraph

## Phase 3 — Pages

- [x] KanjiPage (/kanji/:char): giant kanji centerpiece, badges (JLPT/grade/freq/
